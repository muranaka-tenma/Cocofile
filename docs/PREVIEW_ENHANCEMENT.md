# CocoFile - ファイルプレビュー機能強化

## 概要

ファイルプレビュー機能を大幅に強化し、より快適なプレビュー体験を提供します。

実装日: 2025-12-04

## 実装内容

### 1. 新規コンポーネント

#### TextPreview.tsx
- **目的**: テキストファイルのプレビュー表示
- **機能**:
  - シンタックスハイライト（Prism.js使用）
  - 行番号表示
  - 対応言語: JavaScript, TypeScript, Python, Java, C/C++, C#, JSON, YAML, Markdown, SQL, Bash, CSS, SCSS等
  - コピー機能
  - ダークテーマUI
- **ファイル**: `/frontend/src/components/TextPreview.tsx`

#### FilePreview.tsx
- **目的**: ファイル形式に応じた汎用プレビューコンポーネント
- **機能**:
  - ファイルタイプの自動判定と適切なプレビューコンポーネントへの振り分け
  - エラーハンドリング
  - 対応ファイルタイプ: PDF, 画像, Excel, Word, PowerPoint, テキスト
- **ファイル**: `/frontend/src/components/FilePreview.tsx`

### 2. 既存コンポーネントの強化

#### PDFPreview.tsx の強化
- **追加機能**:
  - ページ入力フィールド（直接ページ番号を入力可能）
  - 最初/最後のページへジャンプボタン
  - キーボードショートカット:
    - `←/→`: 前/次のページ
    - `Home/End`: 最初/最後のページ
    - `+/-`: ズームイン/アウト
  - ズームリセット機能（倍率表示をクリック）

#### PowerPointPreview.tsx の強化
- **追加機能**:
  - スライドナビゲーション（1スライドずつ表示）
  - スライド番号入力フィールド
  - 前後スライド移動ボタン
  - 最初/最後のスライドへジャンプボタン
  - キーボードショートカット:
    - `←/→`: 前/次のスライド
    - `Home/End`: 最初/最後のスライド

#### ExcelPreview.tsx の強化
- **追加機能**:
  - シートタブ表示（複数シートがある場合）
  - シート切り替え機能
  - 自動シート検出（"Sheet1", "Sheet 1", "シート1"等のマーカーを検出）

### 3. FileDetailModal の更新
- **変更点**:
  - 個別のプレビューコンポーネント呼び出しを削除
  - `FilePreview`コンポーネントを使用した統一的なプレビュー表示
  - コードの簡素化とメンテナンス性向上

## 既知の制限事項

1. **Tauri v2の制限**
   - ファイルシステムAPIが`@tauri-apps/api/core`に統合
   - `convertFileSrc`とfetchを組み合わせてファイル読み込み

2. **テキストファイルサイズ**
   - 非常に大きなファイル（10MB以上）は読み込みに時間がかかる可能性
   - 今後、ストリーミング読み込みの実装を検討

3. **Officeファイル**
   - 抽出されたテキストのみを表示（書式、画像、グラフは非表示）
   - シート/スライドの検出は抽出テキストのマーカーに依存

## トラブルシューティング

### プレビューが表示されない
- ファイルパスが正しいか確認
- ファイルの読み取り権限を確認
- ブラウザのコンソールでエラーメッセージを確認

### シンタックスハイライトが動作しない
- Prism.jsが正しくインストールされているか確認
- 対応言語リストを確認
- ブラウザのコンソールでエラーメッセージを確認

### キーボードショートカットが動作しない
- プレビューコンポーネントがフォーカスされているか確認
- 他のショートカットと競合していないか確認
