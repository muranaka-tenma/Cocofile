# ダークモード機能 テストガイド

## テスト環境

- **ブラウザ**: Chrome/Firefox/Safari (開発モード)
- **OS**: Windows/macOS/Linux
- **実行方法**: `npm run tauri dev`

## テストケース

### 1. 基本機能テスト

#### 1.1 テーマ切り替え（ボタン型）

**手順**:
1. 開発モードでアプリを起動
2. 右下の「Dev Navigation」パネルを確認
3. テーマ切り替えボタンをクリック

**期待結果**:
- クリックごとに `ライトモード` → `ダークモード` → `システム設定` → `ライトモード` の順に切り替わる
- 各モードで画面全体の背景色が変わる
- アイコンが適切に表示される (Sun/Moon/Monitor)

#### 1.2 テーマ切り替え（セレクト型）

**手順**:
1. 「Settings」画面に移動
2. 「UI設定」セクションの「テーマ」ドロップダウンを確認
3. 各オプションを選択

**期待結果**:
- 3つのオプションが表示される
- 選択した瞬間にテーマが切り替わる
- ドロップダウンが正常に閉じる

### 2. 永続化テスト

#### 2.1 localStorage保存

**手順**:
1. テーマを「ダークモード」に変更
2. ブラウザの開発者ツールを開く
3. Application → Local Storage → localhost を確認

**期待結果**:
- `cocofile-theme` キーに `dark` が保存されている

#### 2.2 リロード時の復元

**手順**:
1. テーマを「ダークモード」に変更
2. ブラウザをリロード (F5)
3. テーマ状態を確認

**期待結果**:
- リロード後もダークモードが維持される
- ちらつきなく初期表示される

### 3. システム設定連動テスト

#### 3.1 システムテーマ検出

**手順**:
1. テーマを「システム設定」に変更
2. OSのダークモード設定を変更
   - **Windows**: 設定 → 個人用設定 → 色
   - **macOS**: システム環境設定 → 一般 → 外観
   - **Linux**: システム設定 → 外観

**期待結果**:
- OSの設定変更がリアルタイムで反映される
- 手動で変更しなくても自動的に切り替わる

### 4. UI要素テスト

#### 4.1 メインサーチ画面

**手順**:
1. 「Main Search」画面に移動
2. ライト/ダークを切り替え

**確認項目**:
- [ ] ヘッダー部分の背景色が変わる
- [ ] 検索ボックスの背景色が変わる
- [ ] テキストが読みやすい (コントラスト十分)
- [ ] ホットキーヒントの背景色が変わる
- [ ] ボーダーが適切に表示される

#### 4.2 設定画面

**手順**:
1. 「Settings」画面に移動
2. ライト/ダークを切り替え

**確認項目**:
- [ ] カード背景が変わる
- [ ] 入力フィールドが読みやすい
- [ ] ラジオボタン/チェックボックスが見やすい
- [ ] ボタンの色が適切

#### 4.3 スキャン画面

**手順**:
1. 「Scan Index」画面に移動
2. ライト/ダークを切り替え

**確認項目**:
- [ ] ローディング表示が見やすい
- [ ] エラー表示が目立つ
- [ ] 統計情報が読みやすい

#### 4.4 スキャン進捗通知

**手順**:
1. スキャンを実行
2. 右下の進捗通知を確認

**確認項目**:
- [ ] 通知ボックスの背景色が変わる
- [ ] スピナーアニメーションの色が適切
- [ ] テキストが読みやすい

### 5. アクセシビリティテスト

#### 5.1 コントラスト比チェック

**手順**:
1. ブラウザの開発者ツールを開く
2. Lighthouse → Accessibility を実行

**期待結果**:
- コントラスト比が WCAG AA 基準 (4.5:1) 以上
- 警告が表示されない

#### 5.2 キーボード操作

**手順**:
1. マウスを使わずにTabキーで移動
2. テーマ切り替えボタンにフォーカス
3. Enterキーで切り替え

**期待結果**:
- フォーカスリングが表示される
- Enterキーで切り替えが動作する

### 6. パフォーマンステスト

#### 6.1 切り替え速度

**手順**:
1. テーマを高速で連続切り替え
2. パフォーマンスを観察

**期待結果**:
- 遅延なく即座に切り替わる
- メモリリークが発生しない
- CSSトランジションがスムーズ

#### 6.2 初期ロード

**手順**:
1. ダークモードでリロード
2. 初期表示のちらつきを確認

**期待結果**:
- ライトモードが一瞬表示されない (FOUC対策)
- 初期から正しいテーマで表示される

### 7. エッジケーステスト

#### 7.1 localStorage無効化

**手順**:
1. ブラウザのlocalStorageを無効化
2. テーマ切り替えを試す

**期待結果**:
- エラーが発生しない
- デフォルトで「システム設定」が使用される

#### 7.2 prefers-color-scheme非対応

**手順**:
1. 古いブラウザでテスト (または開発ツールで無効化)

**期待結果**:
- システム設定モードでもフォールバック動作
- ライトモードがデフォルトで使用される
